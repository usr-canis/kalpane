# Play Store listing

**App name** (30 max): `Kalpane`

**Short description** (80 max):
`Markdown notes and stylus drawing in one page, versioned in your own GitHub repo.`

**Full description**:

Kalpane (ಕಲ್ಪನೆ) is a notebook for writing and drawing on the same page.

Writing
• Markdown that formats as you type: headings H1–H6, bold, italic, lists, checklists, quotes, links and code blocks with syntax colouring
• Fonts: system Sans, JetBrains Mono, Google Sans Code and Intel One Mono; Kannada supported
• Plain, ruled, dotted or grid paper
• Links between pages with [[Page]], backlinks, and #tags
• Templates for meetings, journals, checklists, lectures and code

Drawing
• Draw anywhere on the page with a stylus: pressure-sensitive pen, highlighter, eraser
• Low-latency ink, palm rejection, pinch to zoom
• Shapes and images you can move, resize, rotate and layer
• Lasso selection

Your notes, your repository
• Notes are plain Markdown files with drawings beside them, stored on your device
• Optional: use a private GitHub repository as the remote. Pull, commit and push a page, a notebook or everything; branches, history, diffs and restoring old versions
• Auto push on Wi-Fi
• No account with us, no ads, no analytics

Also: search, trash with restore, export to PDF or PNG, light and dark themes.

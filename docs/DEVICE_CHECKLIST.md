# Device checklist before production

Run on the Redmi Pad Pro with its stylus, using the internal-testing build from Play.

**Pen**
- [ ] Ink follows the pen tip without visible lag; no flicker when a stroke ends
- [ ] Pressure: Off, Soft, Normal and Strong feel different; ends taper
- [ ] Palm on the screen while writing never draws or scrolls
- [ ] Eraser (whole and partial), highlighter, lasso move/scale/rotate
- [ ] Shapes and an image: move, resize, rotate, forward/backward, delete
- [ ] A long page with many strokes stays smooth when scrolling and zooming

**Text**
- [ ] Typing with the keyboard, Markdown renders on other lines, checkboxes tick on tap
- [ ] Kannada typing and display with each note font
- [ ] Code block, heading menu H1–H6, page style (paper, font, size)
- [ ] [[Link]] opens or creates a page; #tag opens search; backlinks

**Remote**
- [ ] Add remote with a fine-grained token on a private repository
- [ ] Push a page, a notebook, everything; edit on GitHub; pull; view changes; history and restore
- [ ] Branch create and switch; conflict: edit the same page on GitHub and here, then push
- [ ] Auto push runs on Wi-Fi (check the repository after a few hours)

**General**
- [ ] Trash and restore; export PDF and PNG; search; templates
- [ ] Rotate, split screen, dark theme, large system font
- [ ] Kill the app mid-edit and reopen: nothing lost
